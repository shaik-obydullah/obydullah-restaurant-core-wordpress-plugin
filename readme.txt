Core plugin for the Obydullah Restaurant theme with custom post types, menu management, and reservation system.

== Description ==

Obydullah Restaurant Core provides core functionality for the Obydullah Restaurant theme (developed by the same author).

It includes custom post types, custom fields, and restaurant management features such as:

- Hero Slider management
- Chef's Special items
- Menu Items with categories
- Testimonials system
- Opening hours management
- Table reservation system (AJAX + custom DB table)
- Footer settings
- About page builder sections
- Contact page structure

It is recommended for full functionality of the Obydullah Restaurant theme, but can also be used with other restaurant themes with minor adjustments.

== Installation ==

1. Upload the plugin folder to `/wp-content/plugins/`
2. Activate the plugin through the 'Plugins' menu in WordPress
3. Configure settings from admin panels and custom post types

== Frequently Asked Questions ==

= Is this plugin required? =
It is recommended for full functionality of the Obydullah Restaurant theme.

= Does it work without the theme? =
Yes, but it is optimized for the Obydullah Restaurant theme.
